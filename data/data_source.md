# Data Source

This project uses a public dataset containing luxury beauty and cosmetics pop-up event data.

## Dataset Scope

- 2,133 pop-up events
- 24 luxury and premium beauty brands
- 5 global regions
- 26 cities
- Event, product, sales, and footfall metrics

## Source

[View the dataset on Kaggle](https://www.kaggle.com/datasets/pratyushpuri/luxury-beauty-cosmetics-popup-events-kpi-2025)

## Data Usage

The original CSV file is not included in this repository. The dataset remains available through the original source.

The data was used for portfolio and educational purposes only.
